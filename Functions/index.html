Create a python function for movie ticket price.

  1. Accepts these inputs from the user. Number of children, Number of adults, weekday or weekend.
  2. The price is 10$ for children and 13$ for adults.
  3. On a weekday, there is 20% discount.
  4. Based on these inputs, calculate the total price of the movie tickets.
  5. Display output in this format : Final price - amount in $
  6. Example : Final price - 15$

Create a python function for roller coaster ride.

  1. Accepts these inputs from the user. Height and age of the rider
  2. if the height is more than 48 inches, the rider can go on the ride.
  3. if the height is less than 48 inches, but more than 40 inches, the rider can ride with parent.
  4. if the height is less than 40 inches, the rider cannot go on the ride.
  5. Based on these inputs, determine if the rider can go on the ride alone, with a parent, or not at all.
  6. Display output in this format : Ride status - status
  7. Example : Ride status - Can ride with parent
