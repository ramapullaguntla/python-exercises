Student Grade Tracker Exercise

Student Data

You have been given the following dictionary containing student names and their subject grades:

students = {
    "Alice": {"Math": 85, "Science": 92, "History": 78, "English": 90},
    "Bob": {"Math": 70, "Science": 65, "History": 80, "English": 72},
    "Charlie": {"Math": 95, "Science": 98, "History": 92, "English": 97},
    "Diana": {"Math": 60, "Science": 55, "History": 70, "English": 65}
}
Task 1: Calculate Average Math Score
Find and print the average Math score across all students.
Task 2: Calculate Average Science Score
Find and print the average Science score across all students.
Task 3: Find Highest English Score
Find which student got the highest English score and print both the student's name and their score.
Task 4: Find Highest History Score
Find which student got the highest History score and print both the student's name and their score.
Task 5: Find Highest Total Score
Calculate the total score for each student (sum of all subjects) and find which student has the highest total. Print the student's name and their total score.

Expected Output

When your program runs correctly, it should output something like:

Average Math score: 77.50
Average Science score: 77.50
Highest English score: Charlie (97)
Highest History score: Charlie (92)
Highest Total score: Charlie (382)
