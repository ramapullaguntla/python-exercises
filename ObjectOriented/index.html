Build a coffee maker machine using object oriented approach

Implement these features for Coffee maker

  1. Accept type of coffee that user wants (latte, espresso, cappuccino, report)
  2. If the user selects "report", display the current inventory of ingredients.
  3. Create a MenuItem class with properties (name, price, ingredients like water, milk, coffee packets)
  4. Create a coffee maker class with methods to create the requested coffee. It should contain initial inventory of ingredients. (water, milk, coffee packets)
  5. Everytime a coffee is made, update the inventory of ingredients accordingly.
  6. Create a method in coffee maker class to display the current inventory of ingredients.
